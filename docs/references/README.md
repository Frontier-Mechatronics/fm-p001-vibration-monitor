# References

External material informing the program: datasheets, application notes, standards,
measurement technique references, and papers.

## Rules

1. Record the **source and version** — datasheets change silently between revisions, and a
   value read from an unspecified revision is not traceable.
2. **A datasheet value is `predicted`, not `measured`** (AGENTS.md §2). Referencing a
   datasheet never satisfies a physical evidence requirement.
3. Prefer linking with a citation over committing large third-party PDFs. Where a document
   must be committed for offline availability, record why.
4. Note licensing/redistribution constraints for anything committed here.
